# الحاج تكنولوجي — Hajj Tech Tools

مجموعة أدوات تعمل بالكامل داخل المتصفح، بدون سيرفر وبدون إنترنت.

- مولد كلمات سر ذكي
- مولد QR
- عداد الحروف
- فاحص كلمات السر
- النص المزخرف
- ضغط الصور
- قرعة المسابقات

## التشغيل
افتح `index.html` في أي متصفح.
